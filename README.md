# ЛарпМузыка (LarpMusic) — Telegram Mini App

Красивый мини-апп Telegram с музыкой из **интернета, VK, Spotify и Яндекс Музыки**,
переносом плейлистов, полноэкранным плеером, регулировкой громкости, очередью,
перемешиванием и повторами.

## Возможности

| Раздел | Что умеет |
|---|---|
| 🏠 Главная | Рекомендации, быстрый поиск по жанрам, тренды, твои плейлисты |
| 🔍 Поиск | Поиск сразу по выбранным источникам (Интернет / VK / Spotify / Яндекс) |
| ✨ Рекомендации | Анализ твоих любимых треков и истории прослушиваний → персональная подборка |
| 🎶 Моя музыка | Плейлисты, «Любимое», история, добавление треков в 1 клик |
| ⬇️ Импорт | **По ссылке** на плейлист/профиль: Spotify, VK, Яндекс + M3U и локальные файлы |
| ⚙️ Ещё | Токены подключений, громкость по умолчанию, API-прокси, очистка данных |
| ▶️ Плеер | Мини-плеер + полноэкранный: обложка-«винил», перемотка, громкость, очередь, shuffle/repeat, Media Session (кнопки на экране блокировки) |

## Запуск

```bash
cd MusicAppBot
node server.js
# → http://localhost:8080
```

Нужен **Node.js 18+**. Зависимостей нет.

## Публикация на GitHub Pages (бесплатно)

Приложение полностью статическое — его можно раздать напрямую с GitHub Pages,
HTTPS-домен даётся автоматически:

1. Создай репозиторий и закинь **содержимое папки MusicAppBot** в его корень
   (включая `.github/` и `.nojekyll` — они уже добавлены).
2. **Settings → Pages → Source: GitHub Actions** (воркфлоу `.github/workflows/deploy.yml`
   уже лежит в репозитории — после пуша сайт сам соберётся).
3. Адрес будет вида `https://ИМЯ.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

Нюансы:

- **Прокси.** `server.js` на Pages не работает (там нет Node). iTunes и Audius
  работают напрямую из браузера, а для VK/Яндекса задеплой
  **`cloudflare-worker.js`** как Cloudflare Worker (бесплатно, инструкция внутри
  файла) и вставь его URL в приложении: «Ещё» → «API-прокси (CORS)».
- **OAuth-редиректы.** В Spotify/Yandex/VK приложении укажи Redirect URI вида
  `https://ИМЯ.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.
- Сам **бот** на Pages не запустится (это статический хостинг), но для кнопки
  меню бота он и не нужен — см. ниже.

### Доступ из Telegram

1. **@BotFather → /newapp** → выбери бота → укажи HTTPS-адрес (GitHub Pages
   подойдёт) → получишь ссылку вида `t.me/ИМЯ_БОТА/app?startapp=…`.
2. **@BotFather → /menubutton** → тот же адрес — кнопка меню будет открывать ап.
3. Открой бота в Telegram → «Открыть».

Если нужен именно бот с логикой (команды, уведомления) — его придётся держать
отдельно (Railway / Render / Replit / свой сервер), Pages тут не поможет.

## Подключение источников

### 🟢 Интернет (работает сразу)
Поиск идёт сразу по трём источникам без ключей: **Audius** и **Archive.org**
(полные треки — идут в выдаче первыми) плюс **iTunes Search API** (30-сек превью
только как запасной вариант, если полная версия не нашлась). Также играют любые
**прямые ссылки на mp3** и **M3U-плейлисты** (раздел «Импорт»).

### 🔵 Spotify
Импорт **по ссылке**: в разделе «Импорт» → Spotify вставь ссылку на плейлист,
альбом или трек (`https://open.spotify.com/playlist/…`) → «Найти музыку» →
подтверди список → выбери, куда добавить (новая папка / «VK Music» /
«Мне нравится»). Spotify скрывает контент без доступа, поэтому при первом
заходе потребуется подтверждение: [developer.spotify.com/dashboard](https://developer.spotify.com/dashboard)
→ **Create app** → Client ID (используется безопасный **OAuth PKCE**).

### 🔵 VK Музыка
Импорт **по ссылке**: `https://vk.com/music?z=audio-1_123` (трек/альбом),
`https://vk.com/username` или `https://vk.com/club1` (профиль — покажу список
плейлистов). VK скрывает аудио без прав, поэтому при первом заходе нужно
подтвердить доступ (Access Token с правом `audio` или OAuth). Если VK отвечает
ошибкой — это официальное ограничение VK API (с 2016 г. аудио закрыто для
большинства сторонних приложений), ап не при чём.

### 🔴 Яндекс Музыка
Импорт **по ссылке**: `https://music.yandex.ru/users/username/playlists/1002`,
профиль `…/users/username` (покажу плейлисты), альбом `…/albums/123` или трек
`…/track/456`. Яндекс требует OAuth-токен — вставь сервисный токен (или
Client ID → «Войти через Яндекс») в свёрнутый раздел, дальше ссылки работают
автоматически. Переносятся **названия, обложки, альбомы и структура**;
прямое аудио Яндекс отдаёт только своим клиентам — треки без ссылки открываются
кнопкой «в источнике».

### 🟡 M3U и файлы
- **M3U**: вставь ссылку на `.m3u/.m3u8` или текст плейлиста — треки играют сразу.
- **Файлы**: MP3/M4A/WAV/FLAC хранятся локально в IndexedDB (IndexedDB — в браузере),
  ничего не загружается в сеть.

## Про прокси

VK, Яндекс и частично iTunes блокируют запросы прямо из браузера (CORS).
`server.js` содержит **прокси `/proxy?url=…`** с белым списком хостов
(`vk.com`, `yandex.*`, `itunes.apple.com`, `spotify.com`). Путь прокси можно
поменять в настройках, если апп хостится на другом домене.

## Структура

```
MusicAppBot/
├── index.html              # разметка + SVG-иконки
├── css/style.css           # тёмная/светлая тема, Telegram themeParams, анимации
├── js/sources.js           # интернет (Audius + iTunes) / VK / Spotify (PKCE) / Яндекс / M3U

├── .github/workflows/deploy.yml  # авто-деплой на GitHub Pages
├── package.json
└── README.md
```

## Ограничения (честно)

- Spotify и Яндекс **не отдают прямые ссылки на аудио** через свои публичные API —
  поэтому их плейлисты переносятся полностью (метаданные + обложки), а играет
  то, что сервис разрешает (превью / прямые ссылки / локальные файлы / M3U).
- Токены хранятся только в `localStorage` твоего устройства.
- Для публикации нужен свой бот и HTTPS-домен.
